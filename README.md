# xiSage Tap

## How do I install these formulae?

`brew install xisage/tap/<formula>`

Or `brew tap xisage/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "xisage/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
